# Security Policy

## Supported versions

Only the latest release receives fixes. There is no release yet.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub's private reporting instead:
open the repository's **Security** tab and choose **Report a vulnerability**.

Include what you found, how to reproduce it, and the version or commit.

## Scope

In scope: anything that lets the tool run unintended code, or leak or damage files on the user's PC.

Out of scope: how the game's anti-cheat treats third-party tools. This project never reads game
memory or injects code, and requests to add such features are declined.

## Downloads

Only download builds from this repository's Releases page. Builds from anywhere else are not
ours.
