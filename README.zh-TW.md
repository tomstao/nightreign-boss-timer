# nightreign-boss-timer

[English](README.md) | [简体中文](README.zh-CN.md) | **繁體中文**

透過讀取螢幕上的 Boss 血條，記錄《艾爾登法環 黑夜君臨》（ELDEN RING NIGHTREIGN）中每場 Boss 戰的用時。
設計目標是不對遊戲幀數造成可測量的影響。

> 本頁由 AI 翻譯，尚未經母語者審校。如與[英文版](README.md)有出入，以英文版為準。

> **狀態：早期版本，作者本人在用。** 記錄、懸浮視窗、系統匣選單、主視窗、區域標定、全域快速鍵和初次設定
> 均可使用，介面支援 English、简体中文和繁體中文。作者在 2560x1440、遊戲語言為簡體中文的環境下使用，
> 偵測邏輯用 21 段 1920x1080 和 2560x1440 的戰鬥錄影做過測試。其他解析度、超寬螢幕、遊戲語言為英文或
> 繁體中文的情況尚未測試，對幀數的影響也還沒有實測。

## 快速開始

不需要安裝 Python，也不需要下載原始碼。

1. 開啟本儲存庫的 [Releases 頁面](https://github.com/tomstao/nightreign-boss-timer/releases/latest)，
   下載 `nightreign-boss-timer-<版本>-windows.zip`。
2. 把整個 ZIP 解壓縮到一個可寫入的資料夾，例如 `C:\Tools\nightreign-boss-timer`。
3. 執行其中的 `nightreign-boss-timer.exe`。Windows 可能會跳出 SmartScreen 警告，因為程式沒有簽章：
   點選 **其他資訊**，再點選 **仍要執行**。
4. 把遊戲設為 **視窗化** 或 **無邊框視窗**，然後去打 Boss。記錄是自動的。

程式圖示在系統匣裡（時鐘旁邊，可能藏在 **^** 箭頭後面）。點選它可以開啟主視窗。

## 功能

- Boss 血條出現時開始計時，Boss 血量歸零時停止。
- 每場戰鬥儲存為 CSV 檔案中的一列，可直接用 Excel 開啟：日期時間、表格、Boss 名稱、用時、開始和結束時的
  Boss 血量百分比、你的等級，以及你設定的角色。
- Boss 血條清空或出現擊敗文字時，記為 `complete`（已完成）；血條消失而 Boss 還有血量時，記為
  `incomplete`（未完成）。
- 回到之前打過的殘血 Boss，會作為一筆新紀錄，從當時的血量百分比開始。
- 紀錄依表格分組：`Arena`（Boss 競技場 Mod 練習）、`Normal`（正常遊戲），也可以自己新增。
- 在一個小懸浮視窗上顯示表格、Boss、計時和 Boss 血量。懸浮視窗不會攔截滑鼠點擊。
- 全域快速鍵可以自行修改，用於暫停、切換表格等操作。
- 能讀取 English、简体中文和繁體中文的 Boss 名稱，內建 210 個 Boss 的三語名稱。無論遊戲是什麼語言，
  都依你選擇的語言儲存和顯示名稱。
- 紀錄清單支援篩選、顯示每個 Boss 的最佳用時，並可以刪除紀錄。

## 安裝

### 系統需求

| | |
|---|---|
| 作業系統 | 64 位元 Windows 10 或 Windows 11。建議 Windows 10 2004 或更新版本 |
| 遊戲 | ELDEN RING NIGHTREIGN，**視窗化** 或 **無邊框視窗** 模式 |
| 遊戲語言 | English、简体中文或繁體中文 |
| 磁碟空間 | 約 180 MB |
| 記憶體 | 執行時約 200 MB |

不需要安裝其他東西。程式自帶 Python 和所需的一切。

### 下載並執行

見上面的[快速開始](#快速開始)。請保持資料夾內的所有檔案在一起，不要直接在 ZIP 裡執行程式。
只執行從本儲存庫下載的 ZIP。

### 第一次啟動

1. 系統匣（時鐘旁邊）會出現一個圖示，可能藏在 **^** 箭頭後面。
2. 會開啟一個簡短的設定精靈：選擇語言、檢查是否找到遊戲、選擇表格和儲存紀錄的資料夾。
   可以略過，之後再改。
3. 把遊戲設為視窗化或無邊框視窗，去打 Boss。記錄是自動的。
4. 如果遊戲畫面不是 16:9，或者戰鬥沒有被記錄，請標定兩個區域：讓 Boss 血條出現在螢幕上，
   然後按 `Ctrl+Alt+C`。

點選系統匣圖示開啟主視窗：紀錄、表格、快速鍵、區域和設定。**結束** 在系統匣圖示的右鍵選單裡。
各部分的說明見[使用指南](docs/USER_GUIDE.md)（英文）。

### 檔案位置

紀錄和設定儲存在程式資料夾之外，所以更新或刪除程式不會影響它們。

| 內容 | 位置 |
|---|---|
| 紀錄 | `文件\nightreign-boss-timer\records.csv`，除非你選擇了其他資料夾 |
| 設定 | `%APPDATA%\nightreign-boss-timer\settings.json` |
| 記錄檔（回報問題時用） | `%LOCALAPPDATA%\nightreign-boss-timer\logs\app.log` |

把路徑貼到檔案總管的網址列即可開啟。

### 更新

1. 從系統匣圖示結束程式。
2. 刪除或重新命名舊的程式資料夾。
3. 解壓縮新的 ZIP，執行新的 `nightreign-boss-timer.exe`。

### 解除安裝

1. 從系統匣圖示結束程式。
2. 刪除程式資料夾。
3. 如需徹底清除，再刪除 `%APPDATA%\nightreign-boss-timer` 和
   `%LOCALAPPDATA%\nightreign-boss-timer`。只有在不再需要戰鬥紀錄時，才刪除
   `文件\nightreign-boss-timer`。

本工具不安裝驅動程式和服務，不寫入登錄檔，也不往遊戲資料夾裡寫入任何東西。

### 遇到問題

| 問題 | 可以嘗試 |
|---|---|
| 執行後好像沒有反應 | 在系統匣 **^** 箭頭後面找圖示。點選圖示之前，程式沒有視窗。 |
| 程式完全無法啟動 | 先把整個 ZIP 解壓縮出來。檢查防毒軟體有沒有刪除資料夾裡的檔案。查看記錄檔。 |
| 系統匣圖示上有一個金色圓點 | 沒有找到遊戲視窗。請以視窗化或無邊框視窗模式啟動遊戲。 |
| 戰鬥沒有被記錄 | 螢幕上有 Boss 血條時，開啟主視窗的 **區域** 頁面，可以看到工具看到的畫面。用 `Ctrl+Alt+C` 標定。 |
| 快速鍵沒有反應 | 開啟 **快速鍵** 頁面。標有「未生效」的快速鍵被其他程式佔用了，請換一個。 |
| 看不到懸浮視窗 | 把遊戲設為視窗化或無邊框視窗。檢查系統匣選單裡的 **顯示懸浮視窗**。 |
| 錄影裡沒有懸浮視窗 | 在 **設定** 頁面開啟「在截圖和錄影中顯示懸浮視窗」。OBS 請使用「顯示器擷取」。 |

更多內容見[使用指南](docs/USER_GUIDE.md#troubleshooting)。回報問題時，請附上記錄檔，並說明遊戲語言、
解析度和視窗模式。

## 自行建置

需要 [Git](https://git-scm.com/) 和 [uv](https://docs.astral.sh/uv/)。uv 會自動下載合適的 Python。

```powershell
git clone https://github.com/tomstao/nightreign-boss-timer.git
cd nightreign-boss-timer
uv sync --dev
uv run python tools/fetch_model.py
uv run python tools/build_exe.py
```

`fetch_model.py` 下載用於讀取 Boss 名稱的文字辨識模型（21 MB，只需一次）並驗證。`build_exe.py` 產生
`dist\nightreign-boss-timer` 資料夾和對應的 ZIP，大約需要兩分鐘。

從原始碼直接執行（用於開發）：`uv run python -m nightreign_boss_timer.ui.app`。

## 運作原理

本工具是一個獨立的程式，只看螢幕像素。

1. 它複製遊戲視窗中的幾個小區域：Boss 血條、擊敗文字，以及戰鬥開始時的 Boss 名稱和玩家等級。
2. 戰鬥中每秒對血條做十次顏色和形狀檢查，得到 Boss 血量百分比。這一步不使用模型，所以負擔很小。
3. 文字辨識每場戰鬥只執行幾次，在 CPU 上進行，用來在血條出現時讀取 Boss 名稱和等級。
4. 擊敗文字是透過外觀辨識的，不會被當作文字讀取，所以不需要處理語言。

## 安全性

本工具不讀取遊戲記憶體，不注入程式碼，也不修改遊戲檔案。其他讀取螢幕的黑夜君臨工具用的也是這種方式。
但沒有任何第三方工具能保證與反作弊軟體絕對相容，使用風險由你自行承擔。

## 關於 AI 的使用

本儲存庫中的大部分程式碼、測試和文件是在維護者的指導和審查下，用 AI 程式設計助理（Anthropic 的
Claude Code）撰寫的。這樣產生的提交帶有 `Co-Authored-By: Claude` 一行。

這對你意味著：

- 做什麼由維護者決定，每個變更由維護者合併，並且必須通過測試。偵測邏輯用戰鬥錄影驗證，見
  [docs/observations.md](docs/observations.md)。
- AI 寫的程式碼可能看起來正確但其實有錯。沒有測試過的地方，文件裡會寫明。請把它當作早期軟體，
  遇到問題歡迎回報。
- 程式本身不執行任何 AI 服務，也不向任何地方傳送資料。Boss 名稱由一個在你自己電腦上執行的小型
  文字辨識模型讀取。
- 介面的中文文字和本頁都由 AI 撰寫，尚未經母語者審校。
